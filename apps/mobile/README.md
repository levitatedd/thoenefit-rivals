# ThoeneFit Rivals — mobile app

Expo (SDK 58) + React Native 0.88 + TypeScript app for iOS and Android, using Expo Router.

> **All activity data is simulated.** The app does not request health permissions or read from
> Apple Health, Health Connect, or any wearable yet.

Windows setup and how to open the app on a phone: see [docs/DEVELOPMENT.md](../../docs/DEVELOPMENT.md).

## Commands

Run from `apps/mobile`:

| Command             | What it does                                                   |
| ------------------- | -------------------------------------------------------------- |
| `npm ci`            | Clean install of the exact versions in `package-lock.json`     |
| `npm start`         | Start the dev server (scan the QR code with Expo Go)           |
| `npm run android`   | Start the dev server and open the Android emulator             |
| `npm run check`     | Typecheck + lint + format check + tests (run before a PR)      |
| `npm test`          | Unit and component tests (Jest + React Native Testing Library) |
| `npm run typecheck` | TypeScript (`tsc --noEmit`)                                    |
| `npm run lint`      | ESLint via `expo lint` (`eslint-config-expo`)                  |
| `npm run format`    | Auto-format with Prettier                                      |
| `npm run doctor`    | `expo-doctor` project health check (needs internet)            |

Add native-compatible packages with `npx expo install <package>` so versions match the SDK.

## Structure

```
src/
  app/                 Expo Router screens (every file is a route)
    _layout.tsx        Root stack, theme, and activity data provider
    index.tsx          "Today" dashboard (steps + active energy, last 7 days)
    about.tsx          About / data-source info
  features/activity/   Health-data boundary
    types.ts           Normalized DailyActivitySummary + ActivityDataSource adapter interface
    simulated-source.ts  Deterministic simulated adapter (the only adapter today)
    activity-source-context.tsx  Provides the active adapter to screens
    use-recent-activity.ts       Loads recent summaries for the UI
  components/          Shared UI
  constants/theme.ts   Colors (light/dark) and spacing
  utils/               Formatting helpers
```

Future HealthKit (#4) and Health Connect (#5) adapters implement `ActivityDataSource`; scoring (#2)
consumes `DailyActivitySummary` and never talks to an adapter directly.

`ios/` and `android/` are generated by Expo (Continuous Native Generation) and are git-ignored.
